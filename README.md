1. Название и описание задачи
Мини-графический редактор — это консольное приложение на Python, демонстрирующее основные принципы объектно-ориентированного программирования (ООП).
Программа позволяет:
Создавать геометрические фигуры (круги и квадраты)
Скрывать внутренние данные фигур (координаты)
Вычислять площадь каждой фигуры
Подсчитывать общую площадь всех фигур в списке

2. Архитектура проекта
Три кита ООП в коде:
2.1 Инкапсуляция (скрытие данных)
В базовом классе Figure координаты _x и _y сделаны скрытыми. Доступ к ним осуществляется только через публичные методы:
get_coords() — получить координаты
set_coords(x, y) — изменить координаты
2.2 Наследование (переиспользование кода)
Схема:
        Figure (базовый класс)
       /      \
   Circle    Square (дочерние классы)
Figure — хранит общие свойства (координаты)
Circle и Square — наследуют координаты и добавляют свои уникальные свойства (радиус или сторону)
2.3 Полиморфизм (один интерфейс — разная реализация)
В каждом дочернем классе реализован метод calculate_area(), но работает он по-разному. Мы можем в одном цикле вызывать calculate_area() для разных фигур, не зная их точного типа.

3. Пример использования 
- Создаем фигуры
circle = Circle(0, 0, 5)
square = Square(3, 4, 4)
- Получаем координаты
print(circle.get_coords())  # (0, 0)
- Изменяем координаты
circle.set_coords(10, 10)
print(circle.get_coords())  # (10, 10)
- Считаем площадь
print(circle.calculate_area())  # 78.5
print(square.calculate_area())  # 16
- Список фигур
figures = [circle, square]
- Общая площадь
total = sum(fig.calculate_area() for fig in figures)
print(f"Общая площадь: {total}")  # 94.5
